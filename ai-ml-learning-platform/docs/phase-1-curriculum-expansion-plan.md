# Phase 1 Expert Curriculum Expansion Plan

Goal: Expand the MVP from 7 seed lessons into a broader expert-track academy that begins covering the missing concepts needed for AI/ML/LLM mastery and FAANG-style interview preparation.

Architecture: Continue using the local TypeScript curriculum schema. Add lessons with the existing required teaching blocks: beginner explanation, developer explanation, jargon, formulas, algorithms/pseudocode, approaches, mistakes, worked examples, practice ladder, quizzes, and references.

Phase 1 scope:
1. Math foundations: linear algebra, calculus, probability/statistics.
2. Classical ML: classification/logistic regression, trees/ensembles/boosting, clustering/PCA/feature engineering.
3. Deep learning expansion: CNNs, sequence models, transformers/fine-tuning/regularization.
4. LLM engineering expansion: RAG retrieval quality, vector databases, tool calling, agents, evaluations.
5. MLOps/production: data pipelines, drift, monitoring, experiment tracking, model registry.
6. System design: general distributed systems and ML/LLM system design cases.
7. FAANG prep: DSA roadmap, ML interview patterns, behavioral STAR practice.

Definition of done for Phase 1:
- At least 12 new lessons added.
- Each new lesson follows the existing lesson schema.
- Build passes with npm run build.
- Platform honestly shows that this is an expanded base, not final exhaustive coverage.

Next phases after this:
- Phase 2: add 50+ detailed lessons and source ingestion.
- Phase 3: add coding playgrounds and notebooks.
- Phase 4: add mock interviews and adaptive weak-area detection.
- Phase 5: add capstone grading and project review rubrics.
