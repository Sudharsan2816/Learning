# Source Map

This project builds original beginner-friendly learning content inspired by and cross-referenced to the user's learning sources. The app should not copy book/site text verbatim; it should teach concepts in original explanations and link back to sources.

## Content rules
Each lesson must include:
1. Explain like I am completely new.
2. Developer explanation.
3. Jargon glossary inline.
4. Formula/equation breakdown when applicable.
5. Algorithm intuition and implementation-ready pseudocode.
6. Multiple solution approaches and when to use each.
7. Common mistakes and how to avoid them.
8. Worked example with reasoning.
9. Sample problems from easy to hard.
10. Interactive quiz/checkpoint.
11. Links to source references for deeper reading.
